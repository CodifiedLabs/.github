# Support & Enterprise Engagements

Welcome to the Codified Labs engineering hub. Below are the standard channels for getting assistance, resolving integration blockers, and requesting bespoke services.

---

## 1. Public Tier Support (`spec-to-code-rules`)

For users of our open-source tools:
* **Bug Reports:** Open an issue in the [`spec-to-code-rules`](https://github.com/CodifiedLabs/spec-to-code-rules/issues) repository using the provided template.
* **Feature & Adapter Requests:** Propose new IDE or agent adapters through a pull request or issue.
* **Community Help:** Engage via GitHub Discussions.

---

## 2. Pro License Inquiries & Account Access

If you purchased `spec-to-code-rules-pro` and encountered issues with your automated GitHub invitation:
* Ensure your GitHub username entered at Dodo Payments checkout matches your target account.
* Check your pending invitations at: `https://github.com/CodifiedLabs/spec-to-code-rules-pro/invitations`
* For transaction or seat reconciliation: **`billing@codifiedlabs.dev`**

---

## 3. Custom Engineering & Bespoke Rules

Codified Labs builds custom specification pipelines for engineering teams with complex domain requirements:

* **Enterprise Stack Integration:** Custom rules aligned to strict internal frameworks (e.g., Go/gRPC, Rust microservices, multi-region DynamoDB schemas).
* **Monorepo System Rules:** Multi-package context adapters for large Turborepo and Nx enterprise workspaces.
* **Consulting & Implementation:** Direct pairing with Staff Architects to implement Spec-Driven AI workflows across engineering teams.

Schedule an architecture review: **`enterprise@codifiedlabs.dev`**
